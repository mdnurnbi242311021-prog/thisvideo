# AI Medical Ecosystem

A comprehensive medical platform built for Bangladesh's digital healthcare needs.

## Features

- 🏥 **Smart Hospital Portal** — Connected treatment and medical records
- 👨‍⚕️ **BMDC Doctor Directory** — 8,000+ verified doctors with online appointments
- 🔬 **Diagnostic Lab Portal** — Barcode-tracked samples and digital reports
- 💊 **Smart Pharmacy** — Digital prescription verification and medicine services
- 🩸 **Blood Donation Network** — AI-powered compatible donor matching
- 🤖 **Universal AI Assistant** — Medical report analysis and symptom guidance
- 🪪 **One Healthcare ID** — Unified QR-code medical identity card
- 🛡️ **Admin Portal** — System telemetry and RBAC management

## Tech Stack

- **Frontend**: Vanilla HTML, CSS, JavaScript
- **Build Tool**: Vite
- **3D Graphics**: Three.js
- **Animations**: Canvas Confetti
- **Icons**: Lucide
- **Fonts**: Plus Jakarta Sans, Hind Siliguri (Google Fonts)

## Getting Started

```bash
npm install
npm run dev
```
